# Madhumitha B – Portfolio

Open `index.html` in a browser, or host this folder on GitHub Pages, Netlify or Vercel.

- All text lives in `data.js`: edit it to add your email, phone, GitHub, resume and project links.
- Photo: put it in this folder (e.g. `img/me.jpg`) and set `photo: "img/me.jpg"` in `data.js`.
- Resume: add the PDF (e.g. `resume/Madhumitha_B_Resume.pdf`) and set `resume:` in `data.js`.
- Built with React 18 (no build step needed).
